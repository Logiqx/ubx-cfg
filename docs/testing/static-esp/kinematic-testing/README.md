## Static ESP Testing - Kinematic Testing

### Overview

This testing has only focused on static testing, and does not include any kinematic tests (e.g. on the water).

Kinematic testing has previously been performed on the Motion Mini, comparing the performance of 5 Hz and 10 Hz. This consisted of two Motion Mini devices on each bicep with identical configurations. One arm would be recording at 5 Hz, and the other arm would be recording at 10 Hz. The files were then analysed to see whether 5 Hz or 10 Hz produced the most consistent results. Numerous sessions were recorded with the 4 devices being worn on different arms and with different settings, but in all cases 5 Hz was proven to be the most precise.

Similar testing can potentially be performed with the SYRAC GPS, but using the Motion Mini devices as a reference.
