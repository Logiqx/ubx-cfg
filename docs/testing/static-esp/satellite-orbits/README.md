## Static ESP Testing - Satellite Orbits

Why 6 hours?



- Considerations
  - BeiDou has an additional 3 x IGSO and 5 x GEO satellites, so more visible sats in Asia
  - GLONASS inclination angle = 64.8° instead of 55° or 56°, so suitable for high latitudes (typically above 50°)
    - See image at top of https://www.gpsworld.com/innovation-gps-glonass-and-more/



### Inclination Angles

https://courses.ems.psu.edu/geog862/node/1871
- GPS = 55°, BeiDou = 55°, Galileo = 56°, GLONASS = 64.8°
  - See image at top of https://www.gpsworld.com/innovation-gps-glonass-and-more/
- GPS = 6 orbital planes, BeiDou (MEO) / Galileo / GLONASS = 3 orbital planes
  - Additioanlly BeiDou (IGSO) = 2 orbital planes, BeiDou (GEO) = 1 orbital planes

https://orbitalradar.com/navigation-constellations
GLONASS has the highest orbital inclination (64.8°) of any GNSS, giving it superior satellite visibility at latitudes above 55°N. This makes GLONASS particularly valuable in Scandinavia, Russia, Canada, and Alaska where GPS geometry alone can be weaker.
